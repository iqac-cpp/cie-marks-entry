# CIE Mobile First Connected V88.2 - Numeric Keypad Flow

Based on the stable V88.1 version.

## Refinements

1. Mid Exam - 1 and Mid Exam - 2 now prefer the mobile numeric keypad.
2. AB support remains for Mid-1 and Mid-2.
3. After manual SEE Grade selection in Theory + Practical papers, Practical Marks is focused immediately so the numeric keypad opens.
4. Student Admission No. remains hidden; only Hall Ticket No. is displayed.

## Note on AB

Because the numeric keypad is preferred, faculty can still enter AB by switching keyboard manually or using paste when required.

## Use

Replace only GitHub Pages `index.html`.

Apps Script `Code.gs` is unchanged.
